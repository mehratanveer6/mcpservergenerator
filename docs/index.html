MCPForge: an ML-assisted
MCP server generator

MCPForge turns an OpenAPI 3.x or Swagger 2.0 specification into a ready-to-run Model Context Protocol server that an AI assistant can use. Before writing any code it checks the spec, labels every operation as read, write or destructive with a trained classifier, scans descriptions for prompt-injection attacks, and curates large APIs so they do not flood the model's context.

Explore the live demo View source code

How it works

The specification is treated as data and passes through a small ML pipeline. The output is a complete Python project: an MCP server, its tool catalog, a search router, a Dockerfile and a report.

1LoadParse OpenAPI 3.x or Swagger 2.0 and resolve $ref links with a depth limit.
2Spec doctorFind defects that break generated servers and give the spec a health score out of 100.
3Risk classifierRules plus logistic regression label each operation read, write or destructive.
4Poisoning scannerWithhold descriptions with hidden instructions, secret-file requests or invisible Unicode.
5CurateExpose at most 25 direct tools; the rest sit behind search_operations and call_operation.
6Drift checkCompare the new spec with training statistics and publish metrics to CloudWatch.
7GenerateWrite server.py, catalog.json, router.py, a Dockerfile and a report.

    AWS machine learning stack
    
    
    The ML side is written to run on AWS, following the services covered by the AWS Certified Machine Learning Engineer, Associate (MLA-C01) exam. The code is in the aws/ and mcpforge/aws/ folders of the repository.
    
    
    
      
    SageMaker training
    Script-mode training job for the risk classifier with the scikit-learn container. aws/sagemaker_train_deploy.py
    
      
    Automatic Model Tuning
    Hyperparameter tuning of the regularisation strength C, the n-gram range and the vocabulary size, optimising macro F1.
    
      
    SageMaker Pipeline
    Train, evaluate on the gold set, then a quality gate: the model is registered in the Model Registry only if macro F1 reaches the threshold. aws/sagemaker_pipeline.py
    
      
    Serverless inference
    The registered model is deployed to a SageMaker serverless endpoint, so there is no idle cost between generations.
    
      
    Lambda + API Gateway
    The generator itself runs as a container Lambda behind an HTTP API, defined with AWS SAM. aws/template.yaml
    
      
    Bedrock and CloudWatch
    Optional Titan Text Embeddings V2 router and Bedrock description rewriting; drift metrics are published to CloudWatch. mcpforge/aws/
    
    
    
  
    

    


    
  
    
    
    Run it yourself
    
    
    MCPForge is a Python package with a command line interface. The generated server works with any MCP client over stdio.
    

    # install
git clone https://github.com/mehratanveer6/mcpservergenerator
cd mcpservergenerator
pip install -e ".[runtime]"

# inspect a spec
mcpforge doctor examples/petclinic.yaml        # spec health report
mcpforge classify examples/petclinic.yaml      # risk label per operation
mcpforge scan examples/poisoned.yaml           # tool-poisoning scan

# generate and start an MCP server
mcpforge generate examples/petclinic.yaml -o out/petclinic
cd out/petclinic && pip install -e . && python server.py
