
## Safety policy

`MCPFORGE_POLICY` controls which tools are registered and callable:

* `read_only`: only operations classified as read
* `read_write` (default): read and write operations
* `full`: everything, including destructive operations. Use only with human confirmation.

Every tool carries MCP annotations (`readOnlyHint`, `destructiveHint`, `idempotentHint`,
`openWorldHint`) derived from the risk classifier, so clients can ask for confirmation.

## Authentication

* `apiKeyAuth`: set `API_KEY` (sent as header `X-API-Key`)
